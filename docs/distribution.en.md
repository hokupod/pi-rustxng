# License and distribution

pi-rustxng uses **AGPL-3.0-or-later**, matching RustXNG. See [LICENSE](../LICENSE).

This repository and package do not include RustXNG binaries. An explicit installer command downloads the platform binary, LICENSE, and NOTICE from the [official RustXNG v0.31.1 release](https://github.com/sahenjp/RustXNG/releases/tag/v0.31.1). The upstream source is available in the [v0.31.1 source tree](https://github.com/sahenjp/RustXNG/tree/v0.31.1).

Bundling binaries is technically possible, but requires platform-specific assets, storage, and verification for each update. Redistribution also requires a review of AGPL corresponding-source obligations, copyright notices, NOTICE, and dependency licenses. Adding a source URL or LICENSE alone does not establish compliance with every redistribution requirement.

This extension downloads binaries from the official distributor instead of redistributing them. Bundling in a future release would require a separate review of the distribution and source-provision methods.
